# Resumo das Listas de Exercícios 6 a 11

## Lista de Exercícios 6

### Questão 1
**Objetivo**: Resolver problemas de agrupamento e ordenação de registros. Criar e manipular registros, além de usar comparadores para ordenar.
- **Requisitos**: Uso de arrays ou coleções.
- **Exemplo**: Organizar dados de uma tabela de alunos por nota.

### Questão 2
**Objetivo**: Criar um programa para calcular e exibir a média de notas de uma turma.
- **Métodos**: Calcular média e mostrar dados de alunos.
- **Exemplo**: Calcular a média e exibir alunos acima ou abaixo da média.

---

## Lista de Exercícios 7

### Questão 1
**Objetivo**: Implementar uma classe de produtos com métodos para calcular o preço total considerando quantidade e impostos.
- **Requisitos**: Cálculo de impostos com base no preço de cada produto.
- **Exemplo**: Exibir preço total de produtos com impostos aplicados.

### Questão 2
**Objetivo**: Criar um sistema de controle de estoque com possibilidade de adicionar, remover e listar produtos.
- **Métodos**: Adicionar, remover e listar produtos em estoque.
- **Exemplo**: Exibir o estoque atual e as ações feitas no sistema.

---

## Lista de Exercícios 8

### Questão 1
**Objetivo**: Criar classes para representar uma turma e alunos. Implementar métodos para incluir, remover, listar e obter o aluno com melhor nota do ENEM.
- **Classes**: `Turma`, `Aluno`.
- **Métodos**: `incluirAluno()`, `removerAluno()`, `getAlunos()`, `obterAlunoMelhorNotaEnem()`.

### Questão 2
**Objetivo**: Criar uma aplicação com GUI para gerenciar alunos e turmas, com funcionalidades de inclusão e exibição de relatórios.
- **Interação**: Tela para incluir alunos e exibir relatórios.

---

## Lista de Exercícios 9

### Questão 1
**Objetivo**: Criar classes para representar contas bancárias, com herança e métodos para saques considerando limite de crédito.
- **Classes**: `ContaBancaria`, `ContaEspecial`.
- **Métodos**: `setSaldo()`, `sacar()`, `getSaldo()`.

### Questão 2
**Objetivo**: Criar testes para validar o funcionamento da classe `ContaEspecial` em diferentes cenários de saque e limite de crédito.
- **Plano de Testes**: Validar saques superiores ao saldo, saques com limite de crédito e exceções quando o saque ultrapassa o limite.

### Questão 3
**Objetivo**: Adicionar um histórico de movimentos de débito e crédito para cada conta bancária.
- **Classes**: `Movimento`, `ContaBancaria`.
- **Métodos**: `depositar()`, `sacar()`, `getMovimentos()`.

### Questão 4
**Objetivo**: Estender o projeto da questão 3 para incluir a classe `ContaEspecial`, e adicionar validação para movimentações de débito e crédito.
- **Plano de Testes**: Verificar se os movimentos estão sendo registrados corretamente.

---

## Lista de Exercícios 10

### Questão 1
**Objetivo**: Criar um programa para calcular a área de figuras geométricas como quadrados, retângulos, triângulos e círculos.
- **Fórmulas**:
  - Triângulo: Fórmula de Herão.
  - Círculo: Fórmula π * r².
- **Entrada**: Tipo de figura e suas medidas.
- **Saída**: Cálculo da área.

### Questão 2
**Objetivo**: Criar um sistema de gestão de salários de funcionários com diferentes tipos de cálculo para vendedores, programadores e demais funcionários.
- **Classes**: `Funcionario`, `Vendedor`, `Programador`, `DemaisFuncionario`.
- **Métodos**: `calcularSalario()`, `incluirFuncionario()`, `calcularCustosSalarios()`.
- **Exibição**: Mostrar custos totais de salários e detalhes dos funcionários.

---

## Lista de Exercícios 11

### Questão 1
**Objetivo**: Implementar um sistema utilizando interface `Pagavel` para representar despesas como contas de água, mensalidades de ensino e previdência privada.
- **Classes**: `ContaAgua`, `MensalidadeEnsino`, `PrevidenciaPrivada`.
- **Métodos**: `calcularValorPagar()`, `incluirConta()`, `calcularTotalContas()`.
- **Exibição**: Mostrar o total das contas e o saldo de previdência privada, se aplicável.
